# Projeler — bu klasör nedir

Her proje için **notlar, kararlar ve kurulum bilgisi.** Kodun kendisi burada değil,
kendi git deposunda durur.

```
Projeler\
  <proje-adi>\
    00-KUNYE.md        → depo adresi, teknoloji, çalıştırma komutu, ortam bilgisi
    yapilacaklar.md    → o projeye ait iş listesi
    kararlar.md        → mimari kararlar (bağlam · seçilen · elenen · sonuç)
```

## ⚠️ Kod deposu buraya kopyalanmaz
Kasa **notları** tutar. Kodun deposunu buraya klonlamak yedeklemeyi şişirir ve
git geçmişini karıştırır.

## ⚠️ Sır yazılmaz
Parola, API anahtarı, bağlantı dizesi **buraya da yazılmaz.** `00-KUNYE.md` "sır şurada
tutuluyor" diyebilir, sırrın kendisini taşıyamaz.

## Yeni proje açmak
Asistana **"X projesi için klasör aç"** demek yeterli — künyeyle birlikte kurar.
